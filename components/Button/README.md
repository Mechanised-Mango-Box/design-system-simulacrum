# Button

Actions, in three strengths: outlined by default, solid neutral for the main safe action, solid hot for an action that needs a deliberate decision.

Use `.sim-btn` for most actions. Add `.sim-btn--neutral` for the single main action in a panel, such as Save. Add `.sim-btn--hot` only for a decision that can't be taken back, such as Confirm and send, and at most once per view.

Solid buttons take a chamfered top-right corner. The consumer provides a short verb-first label in sentence case.
