# Panel

The window for every grouped surface, marked with corner brackets top-left and bottom-right.

Use `.sim-panel` for side and detail panels. Add `.sim-panel--main` for a main surface that holds its own rows or a graph: it takes the stronger `line` border and a 3px inset that keeps brackets clear of selected rows.

The consumer provides the content and the panel's width. Don't add brackets to banners, inner boxes or graph nodes.
